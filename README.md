# Flint — Open Source FHIR Server on a Data Lake

[![Go](https://github.com/flint-fhir/flint/actions/workflows/ci.yml/badge.svg)](https://github.com/flint-fhir/flint/actions/workflows/ci.yml)
[![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

**Flint** is a cloud-agnostic FHIR R4 server built on Postgres (OLTP) and Apache Iceberg (OLAP). All schema code is generated from FHIR protocol buffers using [proto2type](https://github.com/protocgen/proto2type).

## Architecture

```
EHR → AutoMQ (HL7v2) → Temporal Worker
                           │
              ┌────────────┼────────────┐
              │            │            │
        WriteMedplum  WritePostgres  PublishToAutoMQ
        (temporary)   (resource blob  (JSON)
                       + spidx_*)
                           │            │
                           ▼            ▼
                       Postgres      AutoMQ topic
                       (8 tables     (fhir.flat.v1)
                        per tenant)       │
                                          ▼
                                    Flink DataStream
                                    (JSON → Iceberg)
                                          │
                                          ▼
                                    Iceberg (REST catalog)
                                    nested Parquet + resource_proto
                                          │
                                    Doris / Trino / Spark
```

## Key Design Decisions

- **8 static search index tables** per tenant schema (HAPI pattern). Zero schema changes when adding resources.
- **Schema-per-tenant** physical isolation for HIPAA compliance.
- **`resource_proto`** blob is the lossless source of truth. Search index tables are for `WHERE`/`JOIN` only.
- **proto2type generates everything**: search index extractors, Parquet structs, Iceberg schemas, Flink DataStream jobs.
- **Big 5 first**: Patient, Encounter, Observation, Condition, Practitioner.

## Project Structure

```
flint/
├── pkg/
│   ├── store/postgres/      # Write path + search index insert
│   ├── search/              # FHIR Search → SQL compiler (H3)
│   └── fhirutil/            # Proto nil-safe helpers
├── gen/                     # ALL GENERATED by proto2type
│   ├── go/store/postgres/   # ExtractPatientIndexes(), ...
│   ├── go/store/parquet/    # ParquetPatient, ...
│   ├── iceberg/             # Iceberg schema JSON
│   └── java/flink/          # FlintIcebergJob.java (DataStream)
├── proto/                   # Vendored google/fhir R4 protos
├── fhir/r4/                 # FHIR SearchParameter definitions
├── sql/                     # Static DDL (8 tables per tenant schema)
├── testdata/synthea/        # Proto fixtures
└── buf.gen.yaml             # One command generates everything
```

## Quick Start

```bash
# Generate all code from FHIR protos
buf generate

# Run tests
go test ./...

# Apply schema to Postgres
psql -f sql/schema.sql
```
